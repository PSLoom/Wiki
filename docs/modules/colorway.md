## Purpose

Command-existence-aware syntax highlighting for the interactive PowerShell command line.

## Status

Not started. Its future repository is `PSLoom/Colorway`; no installable module or public verb surface is promised yet. Being in the kernel's first-party allowlist does not mean a release exists. See [the repository map](../contributing/repositories.md).
