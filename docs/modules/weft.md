Weft is a planned harness, not an available implementation.

## Purpose

A zi-style plugin manager using the kernel's [staged application](../guides/sheds.md) to order and defer loading.

## Status

Not started. Work belongs in the future `PSLoom/Weft` repository. Current `Shed` support does not imply that Weft plugin declarations or on-demand loading exist. See [the repository map](../contributing/repositories.md).
